## styleing in react

    global styleing -- index.css and app.css is called as global styleing.
    local styleing -- to create a seperate css file for a component.
    module styleing -- to create a seperate css file for a component .
                        file name in the formate of [fileName.module.css]
    inline styleing -- to implement inline style we need to declear [style] attribute in {{padding:"20px"}}
    object styleing -- we need to declear a styleing property in object with key & value pair
