## react intro

    What is React?
  

  
    1) React is a JavaScript library (not a framework) developed by Facebook (Meta) for building user interfaces (UIs), especially Single Page Applications (SPAs).

    2) It helps developers build reusable UI components that update efficiently when data changes.

    Instead of reloading a whole webpage when something changes, React updates only the parts of the UI that need to change.

    -------
    Why do we need React?

	It makes UI development faster, cleaner, and more efficient.

	Provides a better user experience with smooth updates without page reloads.

## usestate() 

    usestate is a react hook that allows you to add state (data that can change over time)
    to a functional component.

    Normally in js function , variables disappear after the function runs.
    But with usestate, react remembers values b/w re-render.

    syntax:

    const[state,setState]=usestate(initiateValue)

    state-- the current value of the state variables
    setState-- a function that update the state
    initiateValue -- the starting value of the state.

## Routing  &&  nested routing 

    Routing means navigating b/w different pages in a web Applications 
    without refreshing the browser.

    In traditional website , clicking a link reloads the whole pages.

    In react (Single PAge Application), Routing lets us changes the view without reloading


            better performance (no full page reloads)
            Smooth user experience
            Control over navigating without server request.


commend : npm install react-router-dom


    Basic structure

    <BrowserRouter>
        <Routes>
            <Route path="address path" elememt={<component/>}/>
            <Route path="/Home" elememt={<Home/>}/>
            <Route path="/about" elememt={<About/>}/>
        </Routes>
    </BrowserRouter>

    BrowserRouter

        It is the main wrapper component for routing in react app.
        It enables navigation using  the browser  URL's.
        Without this routing  will not work

    Routes

        it contains all the  <Route/> component'
        It tells react router which component to show for thich path
        Only one route will match and render at a time.

    Route

        Defines a specific URL path and which component should load for that path.

## useParams()

    useParams is a hook provided by react router that return an object containing keys/value
    pair of dynamic parameter from the current url.
    These parameter are defined in your router path using  a colon ( : ) followed by parameter name.

    syntax:

        const variables=useParams()


    ex: if you have a route defined as  /blogs/:id the current url is /blog/hello-world ,
        useParams return  {id:"hello-world}

    The colon tells react router that id is a dynamic parameter  - not a literal path segment.


## useNavigate()


    useNavigate is a hook provided by react router that return a function allowing you to

    syntax :

        const variables=useNavigate()
